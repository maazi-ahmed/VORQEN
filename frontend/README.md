### 🎯 Key Design & Styling Principles

- **Theme**: Dark mode, developer-focused aesthetic using an "Obsidian Orbit" palette: deep dark blue/gray backgrounds (`#0B1020`), vibrant purple primary actions (`#A78BFA`), emerald green success/verified indicators (`#34D399`), and amber warnings (`#FBBF24`).

- **Typography & Polish**: Modern, clean sans-serif typography (`Inter`), crisp borders (`border-white/10`), rounded panels (`rounded-2xl`), subtle glassmorphism (`backdrop-blur-md bg-slate-900/80`), and clear status badges.

- **Layout Structure**:

  1. **Left Sidebar**: Top brand header ("VORQEN v1.4 Desktop Core"), active drive indicator (e.g., "D: Drive - 68% (340 GB Free / 1 TB)"), and primary navigation tabs:

     - 📊 Dashboard (Home)

     - 🧹 Organize & Batch

     - 🕵️ Project Detective & Categories

     - 🔍 Storage Detective (Duplicates & Space)

     - 🐧 Migration Advisor (Win-to-Linux)

     - 🛡️ Backup Safety Checker

     - 💬 Ask Your Files (Chatbot)

     - ⚙️ Settings

  2. **Main Content Canvas**: Dynamic view depending on selected tab.

  3. **Embedded AI Assistant Panel**: Persistent or toggleable drawer for conversational queries.

### 🔑 Detailed Views & Feature Requirements

#### 1. 📊 Dashboard (Home View)

- Top summary cards:

  - Total Storage Indexed (e.g., 284.6 GB / 14,820 items).

  - Storage Reclaimable (e.g., 34.6 GB across 14 duplicate groups).

  - Backup Integrity Status (e.g., 94% Verified to `/mnt/backup`).

  - Migration Readiness Index (e.g., 83% Portable to Linux Ext4).

- Quick Action Buttons: "Add Monitored Folder", "Run Storage Analysis", "Start Migration Simulation".

- Storage Footprint breakdown chart or progress bars across Documents, Media, Code/Projects, and Archives.

- Recent AI activity logfeed showing file auto-classifications and verified backup events.

#### 2. 🧹 Organize & Batch Decision Table

- Interactive table showing pending file classifications:

  - Columns: Checkbox, File Name & Path, Size, AI Suggested Category, Rationale & Proof (e.g., "Contains syllabus headings and lecture citations"), Action Status badge, Direct Actions (Keep, Archive, Review).

- Batch Execution toolbar at top: "Selected: X files | Payload: Y GB", with primary buttons: `[Keep Selected]`, `[Archive Selected]`, `[Review Later]`.

- Non-Destructive Safety Banner: Clear notice stating "SAFE MODE ACTIVE: VORQEN never deletes files automatically."

#### 3. 🕵️ Project Detective & Clusters

- Section showing AI-clustered project files scattered across folders:

  - Example Card: "Machine Learning Thesis Pipeline" (5 files across 3 folders: `main.py`, `weights.pt`, `dataset.parquet`, `notes.pdf`, `README.md`).

  - Action button: `[Group into D:\Projects\ML-Thesis]`.

  - Confidence rating badge (e.g., "98.4% Confidence").

#### 4. 🔍 Storage Detective (Duplicates & Cleanup)

- Duplicate groups list grouped by exact SHA-256 hash match:

  - Shows Primary File (e.g., Git-tracked inside project folder) vs. Redundant Copies (e.g., Downloads folder remnant).

  - AI reasoning card explaining which file is safe to prune or archive.

  - One-click action buttons: `[Keep Primary, Archive Copies]`, `[Inspect Diff]`.

#### 5. 🐧 Windows-to-Linux Migration Advisor

- Step-by-Step Migration Progress Bar (1. Review Files → 2. Check Compatibility → 3. Prepare Backup → 4. Dry-Run & Execute).

- Compatibility Findings Table:

  - Flags Windows binaries (`.exe`, `.dll`), Windows scripts (`.bat`, `.powershell`), or Virtualenvs (`.venv`).

  - Recommends Linux alternatives (e.g., Adobe Premiere → DaVinci Resolve/Kdenlive; `.venv` → `requirements.txt` freeze).

  - Flags filename collisions (illegal POSIX characters like `:` or spaces).

- Action buttons: `[Download Migration Script (.sh)]`, `[Approve & Run Migration Export]`.

#### 6. 🛡️ Backup Safety Checker

- Real-time backup verification queue showing SHA-256 / BLAKE3 hashing progress.

- Table listing source paths vs target backup paths (e.g., External SSD `Samsung T7 Shield`), file checksum statuses (`VERIFIED`, `EXCLUDED_RULES`, `LOCKED_FILE`).

- Summary alert badge showing zero bit-rot detection and overall verification percentage.

#### 7. 💬 Ask Your Files (AI Chatbot Panel)

- Chat container with language toggle (`English`, `Français`, `العربية`) and model mode (`Local File LLM - Offline & Private`).

- Preset prompt pills: `"Find my machine learning projects"`, `"Show university PDFs about Hadoop"`, `"Which files can I delete before formatting?"`.

- Interactive message history:

  - User query card.

  - Assistant response card listing matching local files with rich file cards, file paths, tags, compatibility badges ("Safe for Ubuntu/Fedora"), and direct actions (`[Open File]`, `[Mark as Keep]`, `[Archive]`).
